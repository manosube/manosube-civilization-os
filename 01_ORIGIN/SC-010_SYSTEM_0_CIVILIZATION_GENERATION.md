# DEFINITION

文明生成構造とは、存在が状態として現れ、関係を通じて相互に作用し、その作用が場・社会・文明として保持され、再び個々の状態を条件づける過程を記述する体系である。

生成は歴史上最初の文明の誕生だけを指さない。日々の身体・関係・行為・継承・還流を通じて、文明が成立し直す過程を含む。観測と記録は、その過程を認識し、変化を検証し、訂正を可能にする。

本章群は既存SC・MCをつなぐ追加定義である。文明が成立することと、望ましい文明になることは別の問いとして扱う。

# STRUCTURE

## 第0章：存在と成立条件

### 起点

[SC-000](SC-000_EXISTENCE.md)は、存在を定義や操作に先立ってすでにある起点として扱う。[SC-999](SC-999_EXISTENCE_DEFINITION.md)は、存在を位置・流動・周期の中で更新される状態構造として記述する。

体系0では「存在そのもの」と「観測された存在の状態」を区別する。前者を観測記録だけへ還元せず、後者には観測時点・範囲・方法の限界を保持する。二つの記述を接続することを、存在論のすべてが検証済みであるという意味にしない。

人間・身体・環境を対象として、何がどの条件で関係しているかを明示する。対象を単一の評価や役割へ固定しない。対象が存在すること、対象を観測できること、対象へ介入する権限があることは別である。

### 中心命題

文明を構成する存在は、それぞれの状態を持ち、関係の中で変化し続ける。対象は、その対象についての記録より広い。記録がないことを、対象が存在しない証拠として扱わない。同時に、未観測の存在・状態量を捏造しない。

### Agent OSへの接続

開発対象、実行環境、資源、関与主体、対象世界の境界を明示する。人間が定めるObjective・Authorityを、対象世界の存在条件と区別する。`NO_RESULT ≠ PROVEN_ABSENCE`と機能的に接続するが、この原則だけから具体的実装は一意に決まらない。

## 第0.3章：身体と状態

### 世界との具体的な接続

[SC-001](SC-001_BODY.md)に従い、身体を人間が世界と接続する具体的な起点に置く。ひとりの身体状態を文明の最小単位とし、行為・応答・判断を通じて関係へ現れる過程を追う。

| 共通の観測軸 | 身体での観測例 |
|---|---|
| 位置 | 重心・姿勢・接地・関係内の位置 |
| 流動 | 動作・感覚・身体内外の連続性 |
| 周期 | 呼吸・歩行・活動と回復の反復 |

身体の三原則「重心・動作・呼吸」と抽象三軸「位置・流動・周期」を接続する。三力モデル「重力・弾性・回転」とは区別する。各観測例を医学的効果や社会全体への直接的な因果の証明として扱わない。

### 中心命題

ひとりの状態は、その人の内側だけで完結しない。身体の状態は行為・応答・判断を通じて関係へ現れる。その間の行為と関係を観測し、ひとりの身体状態だけから社会全体を断定しない。

### Agent OSへの接続

Repository・Runtime・Infrastructureへの接続を通じて、対象世界の状態を取り込む。身体とAdapterは同一ではない。対応するのは、対象世界に接続し、その影響を受け、状態を観測する機能である。

実際の対象世界、観測で得た事実、保存されたCanonical State、Target Stateを分ける。Canonical Stateは証拠を伴って維持する正式な状態表現であり、外界のすべてを把握した保証ではない。

## 第0.6章：関係と場

### 状態の波及

ひとりの状態が他者との応答へ現れ、関係の重なりが場を形成する。場とは、複数の人の状態、相互作用、共有条件が重なる構造であり、単に人が集まる場所ではない。

状態は同じ形のまま相手へコピーされない。相手の状態、関係の履歴、環境の条件によって受け取られ方が変わる。波及には協調だけでなく、緊張・分断・偏在も含まれる。関係の成立と、その関係が望ましいという評価を区別する。

### 中心命題

ひとりの状態は関係と場へ作用し、関係と場もひとりの状態を条件づける。作用の方向・媒介・文脈・時間差を記録する。片方の状態から、もう片方の状態が必然的に決まると扱わない。

### Agent OSへの接続

依存関係、情報経路、実行経路、権限境界、共有資源として具体化する。接続されていること、情報を受け取れること、変更権限を持つことは別である。READMEやIssueを読めることは、Objective・Authorityを変更する許可ではない。

Differenceは関係そのものではなく、Target StateとObserved Stateの比較から導出する。Authorityは流動そのものではなく、変更を許可するための開発世界固有の統制である。

## 第0.9章：文明生成と還流

### 成立し続ける構造

関係と場での作用が時間を通じて反復され、習慣・制度・文化・記録として保持される。それらが個人の生活条件・行為・身体状態へ戻り、次の関係を条件づける。

生成をたどる方向は「ひとりの状態→関係→場→社会→文明」。実際の影響はその逆方向にも戻る。この区別によってSC-004の生成起点とMC-000の循環を接続する。制度だけを最小起点としないことは、制度から個人への影響を否定することではない。

### 中心命題

還流とは、戻ってきた影響によって起点の状態が更新されることである。その影響は負担を増やす場合も、回復を支える場合もある。還流の有無と改善の成否は、目的と観測結果によって別々に確認する。

MC-013の「入力・変換・出力・還流」を保持し、MC-019・022が扱う循環回復の方向と、負担が戻る現象の記述を区別する。「還流させる」とだけ言って改善を主張せず、何がどこへ戻り、何が変わったかを示す。

### 観測・記録・訂正

前状態、作用、後状態、戻る経路、次の観測を一組で記録する。失敗・未到達・不明も次の状態へ戻す。ログを作ったことだけで循環が成立したとはせず、その記録が次の観測・運用で消費されたか確認する。

### Agent OSへの接続

行為を実行したこと、対象が変わったこと、その変化を確認したことを分ける。確認できた結果をCanonical Stateへ反映し、Lineageを残す。原子的更新・CAS・冪等性は、その還流を壊さず実装する技術的具体化であり、文明OSの式から直接導出された物理法則ではない。

# PRINCIPLE

- 生成方向は分析の起点を定め、還流方向は相互作用を追う。両者を混同しない。
- 成立・持続・改善を区別し、偏在や負担の反復も記録する。
- 観測した状態を存在全体と同一視せず、未観測部分を確定しない。
- 人間の身体経験、AIの分析、開発世界の契約を別の対象として接続する。
- AIは観測条件と案を提示し、人間の採否・責任を代替しない。

# EQUATION

位置×流動×周期などの式は構造関係の記法として扱う。数値化には測定方法・単位・対象範囲・比較条件が必要である。この四章の追記だけで因果法則を実証したとは扱わない。

# OBSERVATION

| 記録項目 | 確認すること |
|---|---|
| 対象・時点・範囲 | 誰・何の、いつの、どこまでの状態か |
| 状態 | 位置・流動・周期を何から捉えたか |
| 行為・関係・場 | 何が媒介し、どの条件で作用したか |
| 保持・還流 | 何として残り、どこへ戻ったか |
| 変化と目的 | 負担・回復・不変・不明のどれが観測されたか |
| 根拠と限界 | 実測・本人の記述・推論・未観測を分けたか |
| 次の観測 | 何を確認すれば訂正できるか |

この表は記録項目の追加定義であり、観測済みログではない。Agent OSのテスト結果で文明論全体を証明しない。
