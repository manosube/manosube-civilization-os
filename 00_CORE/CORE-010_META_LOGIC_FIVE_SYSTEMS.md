# DEFINITION

メタ論理5体系とは、マノスベ文明OSの理論を、生成・基礎・運用・社会実装・メタ構造の五つの問いから接続して読むための構成である。

本定義は2026-10-16の再構築で追加する整理であり、過去からこの名称・区分が正式に存在したという主張ではない。「メタ論理」は本OS内の体系名であり、数学基礎論におけるメタ論理の新しい証明体系を宣言するものではない。

文明を、ひとりの身体状態から関係・場・社会へ展開し、再びひとりの状態へ影響が戻る連続構造として保持する。既存SC・MCの定義を置換する新しい上位原理ではない。

# STRUCTURE

| 体系 | 名称 | 中心となる問い | 既存文書との主な接続 | Agent OSへの機能的接続 |
|---|---|---|---|---|
| 体系0 | 文明生成構造 | 何が、どのようにつながって成立するか | SC系、MC-000、MC-012、体系0本文 | Project・対象世界・接続条件 |
| 体系1 | 文明基礎構造 | 状態をどの原理で捉えるか | MC-010〜018、DATA_A | State・Observation・Difference |
| 体系2 | 文明運用構造 | 変化と還流をどう継続するか | MC-019〜023、CL系、DATA_B | Authority・Change・Evidence・Reflow |
| 体系3 | 社会実装構造 | 異なる主体や環境へどう接続するか | DATA_C、実践・人間接続・分散運用 | Binding・Adapter・Agent・Runtime |
| 体系4 | 文明メタ構造 | 体系自身をどう検証・継承・更新するか | MC-011・022・023、辞典、起動・レビュー | 憲法・不変条件・Schema・Lineage・更新手続き |

この表は主な接続を示す。DATA_A/B/Cを体系1/2/3へ排他的に再分類するものではない。ひとつの章は複数の体系に接続しうる。体系4も他体系の改定を無条件に許す権限ではない。

体系0の章構成は次とする。

| 章 | 見出し | 担当する問い |
|---|---|---|
| 第0章 | 存在と成立条件 | 何を対象とし、何によって成立しているか |
| 第0.3章 | 身体と状態 | 世界との具体的な接続と、その時点の状態 |
| 第0.6章 | 関係と場 | 相互作用・依存・波及・共有条件 |
| 第0.9章 | 文明生成と還流 | 持続・継承・観測・訂正・再成立 |

0・0.3・0.6・0.9は章の識別子であり、測定値や時間間隔ではない。

## 五つの共通観点との区別

「存在・状態・関係・観測・循環」は、すべての体系を横断して用いる五つの共通観点である。「メタ論理5体系」と同じ区分ではない。

| 共通観点 | 確認すること |
|---|---|
| 存在 | 何が対象で、何が未観測か |
| 状態 | どの時点・範囲の位置・流動・周期か |
| 関係 | 何が何に作用し、どの条件で接続するか |
| 観測 | 何をどう捉え、何を記録・検証できたか |
| 循環 | 作用がどこへ戻り、次の状態をどう条件づけるか |

五体系、五つの共通観点、三軸、八層、三十三階層、ディレクトリ区分、Agent OSのKernel八要素は、それぞれ別の分類である。数を合わせるために一対一対応を作らない。

# PRINCIPLE

1. 身体起点を保持する。Agentへの写像のために身体を単なるAdapterへ還元しない。
2. 生成を説明する方向と、実際の影響が戻る方向を区別する。
3. 文明の成立・持続と、望ましい状態への改善を区別する。偏在や負担を維持する循環も観測対象である。
4. 対象世界、観測結果、保存された状態表現、目標状態を混同しない。
5. 観測できないものを不存在とせず、未観測部分を推測だけで確定しない。
6. 比較・修正案は根拠と範囲を明示する。AIの分析を人間の採否・責任へ置き換えない。
7. 親OSの定義、派生OSの設計、実装、テスト、Runtimeでの確認を別々に追跡する。

# EQUATION

文明状態＝位置×流動×周期

文明耐久性＝循環時間－固定時間

崩壊コスト＝直線化×固定時間

これらはREADMEに従う構造関係の記法であり、測定方法・単位・適用条件が定義されるまでは数値計算や実証済み因果法則として扱わない。5体系はこれらを置換する新しい方程式ではない。

# OBSERVATION

体系を用いる際は、対象・時点・範囲・接続先・戻る経路・根拠・未確認事項を記録する。概念間の接続が説明できたことと、現実でその関係が確認できたことを分ける。

Agent OSの結果は開発世界における写像の評価へ戻せるが、それだけで身体・社会・文明全体への因果関係を証明したとは扱わない。
