# カタカムナウタヒ八〇首：聴く・唱える実践

本資料は[BP-005](../BP-005_KATAKAMUNA_PROTOCOL.md)を実践するための入口である。2026-10-25のSHUKOUの指定に基づき、聴くことと唱えることの両方をバランスよく行う。**意味を理解する必要は全くない。** 意味の学習・翻訳・解釈・暗記は、開始や継続の条件ではない。

## 最初の使い方

1. 無理なく過ごせる姿勢で、いまの状態を短く確かめる。
2. 今回扱う首や範囲を、[首の索引](UTAHI_INDEX.md)から選ぶ。八〇首全部を一度に行う必要はない。
3. 聴く時間と、自分で唱える時間を設ける。交互に行っても、聴きながら唱えてもよい。自分の声を聴きながら唱えることもできる。
4. 聴取だけ、発声だけへ偏り続けていないかを振り返り、その日の状態に応じて両方の時間や順序を調整する。比率を一律に1対1へ固定しない。
5. 一度休み、前後の違い・違いがないこと・分からないことを本人の言葉で記録する。[記録用紙](../../05_DATA_LAYER/CL_RUNTIME/TEMPLATES/CL-TEMPLATE-005_KATAKAMUNA_PRACTICE.md)を使える。

バランスの調整は実践者が行う。AIが「正しい比率」や達成点を自動で決めない。八〇首の通唱、特定の理解、特定の体感を実践者に求めない。

## 聴くこと・唱えること

聴くときは、声の続きや間、自分の呼吸や姿勢に注意を向けてもよい。唱えるときは、意味を考えようとせず、無理のない声と息で行える。途中で途切れたり分からなくなったりした場合は、止まる・聴く側へ戻る・範囲を短くすることができる。

詞章を同じ箇所から再開するための確認と、発音を力んで作り込むことは区別する。初めから正確な暗唱や特定の響きを達成する必要はない。

無理に声量を上げたり息を長く保ったりせず、疲れ・苦しさ・違和感があれば休むか終了する。まずは一本下駄と別の実践として行い、同時実施を必須にしない。

## 三軸で記録する

| 観測軸 | 記録できる例 |
|---|---|
| 位置 | 実施時の姿勢・支持、本人が響きや緊張を感じた部位 |
| 流動 | 声・息・動作のつながり、途中で変わったこと、詰まりの本人記述 |
| 周期 | 聴取・発声・休止の順序、反復回数、時間、本人が気づいた呼吸の変化 |

これは観測項目の例である。実践者の自由な記述を、三軸の言葉へ無理に置き換えない。本人の感覚、実施条件、計測値、AIの解釈を区別する。変化なし・不快・不明も記録する。

## AIが担う役割

- 首ID、PDFページ、実施範囲と記録を対応付ける。
- 本人の記述を保持し、異なる日の条件や変化を比較できるよう整理する。
- 意味理解を求めず、求められていない詞章の解釈や神秘的説明を実践へ差し込まない。
- AI自身が人間と同じ身体感覚を得たとは述べない。本人の感覚から、他者・場・社会全体の状態を確定しない。
- 記録が次の実践の調整にどう使われたかを確認する。ログを作っただけで改善や還流の成立を断定しない。
