# DEFINITION

HIDDEN STATE LOGとは、
表層に現れていない状態、すなわち**潜在状態・未顕在状態・抑圧状態・遅延状態**を観測・記録する文明ログである。

このログは、可視化されている事象の背後に存在する構造的要因を捉えるために用いられる。

---

# STRUCTURE

HIDDEN STATE LOGは以下の五層で構成される。

1. SURFACE_STATE（表層状態）
2. HIDDEN_STATE（潜在状態）
3. TENSION_LEVEL（緊張度）
4. RETURN_POTENTIAL（還流可能性）
5. COLLAPSE_RISK（崩壊予兆）

---

# PRINCIPLE

原則は以下の通りである。

・表層状態は必ずしも実態を反映しない
・潜在状態の表出時期や緊張・崩壊との関係は個別に検証する
・記録の仮説を本人の内面や確定した原因へ置き換えない

表出の記録と、未確認の仮説・欠損を分けて保持する。
全体量が不明なときは差分を算出できない。

---

# 観測・推定・未確認の境界

本人の申告・観測できた事実・AIの推論・未確認事項を分ける。可視情報が全体を尽くすとは限らないが、特定の潜在状態が存在すると推論だけで確定しない。未観測は不存在の証拠でも存在確定の証拠でもない。

式は構造関係の記法である。測定方法・単位・対象範囲・適用条件・データが揃わない場合、量・差分・比率・確率・危険度は算出不能または不明と記録する。空欄を0や推定値で埋めない。計算条件が揃う場合も、使用データ・方法・不確実性を記す。

仮説には根拠、対立仮説、本人への確認または観測方法、反証条件を添える。本人に確認できない内面を代弁せず、否定や追加観測を受けて訂正・撤回する。ログは次の確認・行動にどう使われたかを追跡し、記録だけで改善を断定しない。

# EQUATION

潜在状態観測式：

HIDDEN_STATE = TOTAL_STATE - SURFACE_STATE

緊張生成式：

TENSION = HIDDEN_STATE × 固定時間

崩壊予兆式：

COLLAPSE_RISK = TENSION × 非還流時間

還流可能性：

RETURN_POTENTIAL = 流動量 × 周期同調率

---

# OBSERVATION

以下は本人申告や別の根拠があるときの記録対象例であり、外見だけで内面を確定する規則ではない。

・表面上は穏やかだが内部に抵抗がある
・合意は成立しているが納得が伴っていない
・行動はしているが内側に停滞がある
・成功しているが疲労が蓄積している

説明用の仮想例（実測結果ではない）：

SURFACE_STATE：笑顔・肯定・実行を観察した
HIDDEN_STATE：不明。不安・抵抗は確認前の仮説に留める
TENSION_LEVEL：未確認
RETURN_POTENTIAL：未確認
COLLAPSE_RISK：判定根拠不足
ALTERNATIVE：納得して実行している可能性も残す
NEXT_CHECK：本人が望む範囲で納得・負担・実施条件を確かめる

# SUMMARY_FOR_AI

HIDDEN STATE LOGは、
表層では観測できない潜在状態を記録するためのログである。

本ログは以下を目的とする：

・状態のズレの検出
・緊張の蓄積の可視化
・崩壊予兆の早期観測
・還流不全の特定

AIは、表層データのみで判断してはならない。
本人申告・観測・推論・未確認を区別し、根拠・対立仮説・確認方法・反証と訂正を記録せよ。
計算条件がなければ差分・確率・危険度は不明とし、算出を強制するな。
次の観測・行動にどう戻したかを追跡せよ。
